# 공동 개발 작업 안내

이 저장소는 금오공대 기계공학전공 졸업 길잡이의 공동 개발용 사본입니다.
먼저 README.md, TEAM_GUIDE.md, data/KNOWLEDGE_NOTES.md를 읽으세요.

## 작업 방식

- 기능 하나 또는 관련 버그 하나를 작업 브랜치에서 처리합니다. 최신 main을 기준으로 시작합니다.
- main에 직접 푸시하지 않고 변경 이유와 검증 결과를 PR에 적습니다. 다른 팀원이 검토한 뒤 병합합니다.
- 요청된 범위의 작업과 필요한 검증을 마무리합니다. 이미 받은 승인을 반복해서 요청하지 않습니다.
- 이 저장소의 기본 작업 범위는 코드 수정·검증·PR입니다. 운영 사이트 배포는 별도로 요청된 배포 작업에서 담당자가 수행합니다. GitHub 병합은 기존 Sites의 배포와 연결되어 있지 않습니다.
- 같은 파일을 동시에 크게 변경하게 되면 PR 설명에 충돌 가능 부분을 적고 작은 변경으로 나눕니다.

## 프로젝트 구조

- dist/: 실제 서비스 HTML·CSS·JavaScript. 별도 프레임워크 빌드 없음.
- dist/knowledge.js, dist/data/catalog.js: 졸업 기준과 교육과정.
- dist/academic.js, dist/transcript.js: 성적표 집계·PDF 인식.
- dist/advisor.js, dist/advisor.css: 선택형 상담.
- data/: 원본 교과자료와 검토 기록. 개인 성적 자료는 포함하지 않음.
- checks/: 규칙 검사와 합성 자료를 이용한 브라우저 검사.
- scripts/: 자료 정규화·PDF 생성·정적 OCR 의존성 갱신.

## 유지할 제품 조건

- 파란색 디자인, 처음 화면 복귀·상담 이어보기, 짧은 선택형 답변.
- 추천 학기는 학생이 매번 선택하며 실제 개설 확정으로 표현하지 않음.
- 전필·전선과 교양·MSC를 분리하고, 현재 수강은 취득학점에 더하지 않음.
- 과거 학번의 전필·전선 최소학점을 새 교육과정 기준으로 추정하지 않음.
- PDF 인식은 초안이며 원본 합계 대조와 학생 확인 이후에 적용.
- 학생 원본 PDF·인적사항·추출 원문을 서버로 전송하거나 저장소·샘플에 추가하지 않음. 분석 로컬 저장은 선택 사항.
- SSU 직접 이수와 동일인정 후보를 구분. 인증 포기나 졸업 확률을 자동 판정하지 않음.
- 졸업 기준 변경에는 공식 근거와 적용 학번을 기록하고 관련 안내·검사를 함께 갱신.

## 검증

Node.js 24를 권장합니다. 프로젝트 루트에서 `npm ci`와 `npm test`를 실행합니다.
변경과 관련된 의미 있는 검사만 추가합니다. 단순 문구·색상 변경을 위한 구현 복제 테스트는 만들지 않습니다.
화면 변경은 HTTP 로컬 서버와 브라우저에서 확인합니다. TEAM_GUIDE.md의 실행법을 따르세요.
브라우저 검사를 실행할 수 없다면 그 한계를 PR에 명시합니다.
라이브러리 갱신 외에는 dist/vendor/의 제공 파일을 직접 수정하지 않습니다.
