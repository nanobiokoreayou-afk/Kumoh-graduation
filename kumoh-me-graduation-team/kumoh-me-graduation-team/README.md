# 금오공대 기계공학전공 졸업 길잡이

**공동 개발 시작:** [TEAM_GUIDE.md](TEAM_GUIDE.md)의 GitHub 생성·초대·Codex 연결·PR 절차를 따르세요. 각 Codex 작업은 [AGENTS.md](AGENTS.md)의 팀 규칙을 읽습니다. 이 사본에는 운영 사이트 배포 연결이 없으며 GitHub 저장소로 옮긴 뒤에도 기존 사이트와 자동으로 동기화되지 않습니다.

국립금오공과대학교 기계공학부 **기계공학전공** 학생을 위한 비공식 시범 웹 챗봇입니다.

## 제공 기능

- 2000~2026 입학 연도·인증과정별 졸업학점과 질문 유형별 안내
- 파란색 디자인, 대화를 유지하는 처음 화면 복귀와 상담 이어보기
- 전공필수·선택 학점 분리 입력, 합계·부족 학점 계산과 비교과 체크리스트
- 전공필수 13과목·전공선택 23과목의 개별 이수 기록
- 학생이 매번 연도·학기·학년을 선택하는 수강 후보 추천
- 미이수 필수 우선, 편성학기·계획학점·일부 선수관계·관심 분야 반영
- 융합전공 동일인정, 취업진로교육 등 엑셀 기반 답변과 과목코드 검색
- 졸업요건·비교과, 교과목 편성, 융합전공 PDF 열람·다운로드
- PC·모바일 화면, 브라우저 로컬 저장·삭제, 점검·수강계획 텍스트 저장
- 대화창에서 개인 PDF 성적표 입력, 텍스트·이미지 인식 후 학생 확인·수정
- PDF가 없으면 1학년 1학기부터 학기별 과목 선택, 현재 수강과 취득 완료 분리
- 짧은 선택형 상담: 학적 → 이수내역 → 현재 수강 → SSU·AI로봇·MD → 요약
- 현행 필수과목 대조, 전필·전선 및 교양·MSC 집계, 인증 유지·비인증 시나리오 비교

이 버전은 **규칙 기반 안내 챗봇**입니다. 외부 LLM API, 학교 학사시스템, 학생 계정과 연동하지 않습니다. 대화는 현재 페이지 메모리에 저장합니다. 직접 입력한 학적·학점·체크리스트는 localStorage에 저장합니다. 성적표에서 가져온 과목·성적·분석은 기본적으로 세션에서만 유지하며 학생이 별도로 선택한 경우에만 localStorage에 저장합니다. 추천 연도·학기는 저장하지 않습니다.

## 성적표 처리

PDF 원본, 파일명, 이름·학번, 전체 추출 텍스트는 업로드하거나 저장하지 않습니다. PDF.js 6.4.299와 Tesseract.js/Core 7.0.0, 한국어·영어 모델을 같은 사이트에서 불러와 브라우저에서 처리합니다. 이미지 PDF는 금오공대 3열 성적증명서 양식에 맞춰 열을 분리합니다. 20MB·8쪽 이하 PDF를 지원하며 암호 PDF, 다른 스캔 양식, 판독 실패는 수동 입력으로 안내합니다. 첫 OCR은 기기·다운로드 속도에 따라 시간이 걸립니다.

OCR 결과는 초안입니다. 과목명·학점·성적·평점을 검토하고 확인해야 분석에 반영됩니다. PDF 총 취득학점 입력은 필수이며 합계 불일치, 미확인 성적, 재수강 중복이 있으면 적용을 막습니다. 오인식한 과목은 자동으로 비슷한 과목에 연결하지 않고 수정 후보를 보여줍니다. 과거 이수구분을 유지하되 확인 가능한 MSC는 교양과 분리합니다. F·U·NP는 취득에서 제외하고 0학점 상담 이수는 학기별로 유지합니다.

현재 수강과목은 취득학점에 합산하지 않습니다. 다음 학기 계획은 현재 과목 통과 조건, 필수 우선, 교양 자리 확보 및 확인된 선수관계를 반영합니다. 일반 신입학 외 학적은 자동 충족 판정을 막습니다. SSU 특성화사업 참여와 융합전공 등록을 구분하고, 동일인정 학점을 자동 추가하지 않습니다.

8학기 점검은 확인한 등록학기와 **학기당 18학점 계획**을 비교하는 참고 계산입니다. 학교의 개인별 수강상한이나 졸업 확률을 뜻하지 않습니다. 낮은 최근 평점(상담 표시 기준 1.75 미만)은 수강 부담 점검만 안내합니다. 인증 경로 비교는 학적을 바꾸지 않으며, 부족 MSC가 이미 0이면 비인증 전환으로 줄어드는 학점도 0으로 안내합니다. 설계·상담·학습성과, 과거 학번 경과조치는 별도 확인합니다.

## 자료와 적용 범위

검토일: **2026-10-30**. `data/KNOWLEDGE_NOTES.md`에 데이터 검토·적용 기록을 보관합니다. 이는 프로젝트의 지속 가능한 지식 데이터이며 계정의 별도 메모리 기능이 아닙니다.

- 사용자 제공 `교과목 자료.xlsx`: 6개 시트, 원본과 셀 위치 보존. 앞서 제공한 파일과 해시가 같으므로 별도 근거로 중복 집계하지 않습니다.
- 전공·기초·MSC·교양 130개 코드, SSU 121과목, AI로봇 51과목.
- 2026 교육과정 운영기준 및 편성표: 기계공학전공 17~20쪽, 사회봉사 16쪽.
- 2026 공학교육인증 안내서: 기계공학심화 최소달성기준 23쪽.
- 2026-2 논문 공지, 2027년 2월 졸업예정자 학습성과 공지.

2026 기준표는 2015 이후 전공 71학점, 2014 이전 65학점, 졸업 130학점을 기재합니다. 2025 이후의 기본전공32·추가선택39 경로를 구학번의 전필·전선 최소학점으로 추정하지 않습니다. 교양 입력값은 MSC를 제외합니다. 기존 저장된 전공 합계는 임의 분할하지 않고 재입력을 안내합니다. 미입력과 0학점을 구별합니다.

**추천은 교육과정 편성학기 기준 후보**입니다. 실제 학기별 개설·시간표·정원·수강제한은 원본에 없습니다. 융합전공의 빈 학년·학기·학점을 기계공학 동일인정 과목으로 채우지 않습니다. 확인된 일부 선수관계만 반영합니다. 추천 학년 이후의 필수는 별도로 집계하며, 다른 학기 필수는 당해 학기 후보에서 분리합니다.

교육과정 개편·경과조치·학적 변동의 개인 적용은 별도 확인이 필요합니다. 총학점 충족을 졸업 가능으로 판정하지 않습니다. 같은 과목의 중복행과 동일인정 과정 학점을 총학점에 이중 합산하지 않습니다. 문서 안의 내용은 데이터로 취급하며 작업 지시로 실행하지 않습니다.

## 실행과 검증

정적 HTML/CSS/JavaScript 앱이며 빌드가 필요 없습니다. Node.js 24와 Python 3를 권장합니다.

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
npm test
python checks/browser_qa.py
python checks/advisor_qa.py
```

브라우저 검사는 자체 로컬 서버(4174)를 실행합니다. Playwright가 필요하며 설치된 Chromium 또는 Playwright에서 내려받은 브라우저를 사용합니다. 선택적으로 `KIT_CHROMIUM_EXECUTABLE`에 실행 파일 경로를 지정할 수 있습니다. 처음 화면 복귀·대화 보존, 분리 학점, 이수목록, 필수·선택 추천, 학기 재선택, PDF·텍스트 다운로드, 학적 예외, 저장·삭제, HTML 입력 처리, 모바일 화면을 확인합니다.

`advisor_qa.py`는 가상의 PDF를 임시 폴더에서 생성하여 업로드·합계 대조·단계 이동·학기 추천·저장 동의·삭제·모바일을 검사합니다(4176, reportlab 필요). 실제 학생 자료는 저장소나 테스트 fixture에 포함하지 않습니다. `npm test`는 학점 분류·F·재수강·동일인정·추천 제약을 포함한 26개 검사를 실행합니다.

OCR 정적 라이브러리와 라이선스는 `dist/vendor/`에 있습니다. `npm ci` 후 `python scripts/vendor_transcript_assets.py`로 갱신할 수 있습니다. 언어 모델은 해시를 검증하며 버전 변경 시 PDF 인식 검사를 다시 수행하세요.

## 데이터·PDF 갱신

```sh
python scripts/import_curriculum.py
python scripts/build_guides.py
cp output/pdf/kit-*.pdf dist/docs/
```

원본은 `data/source-workbook.xlsx`, 정규화 데이터는 `dist/data/catalog.js`와 `catalog.json`, 셀 원문은 `data/workbook-cells.json`입니다. PDF 생성에는 reportlab, fontTools, pypdf와 Noto CJK 글꼴이 필요합니다. 생성물은 `output/pdf/`, 배포 파일은 `dist/docs/`입니다. 원본 엑셀과 생성 스크립트는 공개 정적 산출물에 포함하지 않습니다.

자료 변경 시 지식 규칙·출처·검토일·PDF 페이지 메타데이터도 갱신하고 테스트와 PDF 시각 검토를 수행하세요. 수강지도 HWP 본문은 열람하지 못했으며 개인별 경과조치와 최신 실제 개설표는 추가 대조 대상입니다.
